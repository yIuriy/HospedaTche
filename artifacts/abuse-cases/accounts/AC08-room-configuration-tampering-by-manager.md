### AC08 - Room Configuration Tampering By Manager

Actor: malicious Manager.

Goal: alter legitimate room configuration.

Conditions: Manager has valid access to the room management module.

Abuse flow:
1. Malicious Manager logs in with valid credentials.
2. Manager opens the room management module.
3. Manager changes room configurations.
4. Room information becomes incorrect and hotel operation is disrupted.

Impact: hotel operation disruption, incorrect room data, booking errors, and delayed guest service.

Related STRIDE categories: Denial of Service, Tampering
