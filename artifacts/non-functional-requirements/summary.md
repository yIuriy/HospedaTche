# Non-Functional Requirements Summary

## Scope

HospedaTche non-functional requirements define basic quality attributes for security, performance, availability, reliability, usability, accessibility, maintainability, and privacy.

These requirements stay general. Module-specific threats and abuse cases should be added by each member in STRIDE and abuse case artifacts.
