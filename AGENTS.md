# AGENTS.md

## Project

HospedaTche is a hotel accommodation system for the Secure Software Engineering course.

## Language Rules

- All repository documentation must be written in English.
- User-facing UI text may be written in Portuguese.
- Code identifiers should prefer English unless required by a framework or external contract.

## Repository Layout

- `ai/`: AI-facing project context, assignment instructions, decisions, and working notes.
- `system/backend/`: future backend application.
- `system/frontend/`: future frontend application.
- `artifacts/`: course deliverables, diagrams, images, and supporting files.

## Work Rules

- Keep changes small and focused.
- Reuse existing structure before creating new folders.
- Do not run full test suites unless explicitly requested.
- Preserve user changes.
- Prefer clear commits that describe real contributions.

## Security Focus

Prioritize assets, actors, trust boundaries, STRIDE threats, and abuse cases. Avoid implementation details until the analysis artifacts are clear.
